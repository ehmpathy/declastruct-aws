- **kind** = fix
- **owner** = whoever next touches `provision/aws.auth/account=demo/`
- **rank** = 🔴 **first**, ahead of every other dream this stone caught. an independent peer lane
  (r011, round 3) walked the whole provision and graded this the largest structural gap the stone
  leaves open, with the advice to take it as the very next follow-up once that file is next opened
- **caught** = 2026-09-08, on `.behavior/v2026_09_06.feat-demo-trusts-ahbode-grove` stone `5.1.execution.from_vision`

## .the cue that fired

the grove-reach runbook's single most dangerous gesture is the **silent** one: remove a resource from
`getResources()` and declastruct emits no plan row, no warn, and no error — the role stays live,
still trusted, now unmanaged (`case=7` `[t3]`).

⇒ the natural clamp is a test that asserts the aggregator still carries the reach set. i reached for
it, and it is unavailable.

## .the gap, precisely

`getResourcesOfOidc` reads live aws credentials **at declare time**:

```ts
// provision/aws.auth/account=demo/resources.oidc.ts:22-24
export const getResourcesOfOidc = async (): Promise<DomainEntity<any>[]> => {
  const provider = await getDeclastructAwsProvider({}, { log });
  const accountId = provider.context.aws.credentials.account;
```

and `getResources()` awaits it:

```ts
// provision/aws.auth/account=demo/resources.ts:22-24
export const getResources = async (): Promise<DomainEntity<any>[]> => {
  return [...(await getResourcesOfOidc()), ...(await getResourcesOfReach())];
};
```

⇒ **so the aggregator cannot be called from a unit test.** `resources.reach.test.ts` covers
`getResourcesOfReach()` — which is credential-free — and cannot speak to whether the aggregator still
composes it. the one gesture that fails **silently** is the one gesture with no check behind it.

🟡 **and the gap is wider than this wish.** every future producer under `account=demo` inherits it,
and the same shape sits in `account=.root/resources.ts`.

🔴 **a SECOND named hazard is blocked by the identical line**, found by a different review lane: the
vision's edgecase table names *"someone bolts a second trust statement onto `ehmpathy-demo-oidc`"* and
prescribes a plan-diff check. what it cannot have is a **test** — `getResourcesOfOidc()` is
uncallable without a credential, so its own one-statement invariant is as unclampable as the
aggregator's composition.

⇒ **so the fix does not buy one test. it unblocks every structural clamp under `account=demo`.**

## .the shape of the fix

the account id is the only credential-derived value in `getResourcesOfOidc`. lift it to an input:

```ts
export const getResourcesOfOidc = async (input: {
  accountId: string;
}): Promise<DomainEntity<any>[]> => { ... };
```

and read it once, in the aggregator, beside the provider it already builds:

```ts
export const getResources = async (): Promise<DomainEntity<any>[]> => {
  const provider = await getDeclastructAwsProvider({}, { log });
  return [
    ...(await getResourcesOfOidc({
      accountId: provider.context.aws.credentials.account,
    })),
    ...(await getResourcesOfReach()),
  ];
};
```

⇒ **then a credential-free `getAllResourcesDeclared({ accountId })` can hold the composition**, and
`resources.test.ts` can assert it carries every resource `getResourcesOfReach()` declares. that
converts the silent gesture into a red test on the commit that makes it.

⚠️ it also removes a **second** credential read — the aggregator already builds a provider in
`getProviders()`, so today the demo wish reads credentials twice per plan.

## .why it is not done in this round

**SAFE — no.** it edits `resources.oidc.ts`, the incumbent this wish's acceptance list requires be
**unchanged and provable by diff**:

> *"`ehmpathy-demo-oidc` and the SSO permission set are **unchanged** — a diff proves it"*

⇒ a signature change there would break that criterion on the commit that delivers the wish.

**CLEAN — no.** it ripples: the oidc producer, the aggregator, `getProviders`, and a new
`resources.test.ts` with its own snapshot. that is a second wish, not a ride-along.

⇒ the deferral is a judgment about ripple cost, so it owes a fulcrum as well as this dream —
recorded at `.behavior/v2026_09_06.feat-demo-trusts-ahbode-grove/.fulcrums/`.
