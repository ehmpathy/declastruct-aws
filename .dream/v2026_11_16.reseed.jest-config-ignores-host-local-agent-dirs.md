# 🌙 dream: jest configs ignore host-local `.agent/.cache` and `.agent/.actors`

kind: reseed · owner: declapract best-practices (the jest config templates) · caught 2026-11-16

## .the cue that fired

a full local unit run (`rhx git.repo.test --what unit --mode apply --thorough`) read `1419 passed, 6 failed`. every failure sat in a host-local, untracked dir:
- `.agent/.cache/repo=ehmpathy/role=mechanic/skill=rmsafe/trash/.agent/repo=.this/role=any/skills/aws.auth.demo.plan.test.ts`: a test `rhx rmsafe` moved to its trash, still found and run by jest
- `.agent/.actors/actor.via.repo=ambient/brain/.claude/plugins/…/tests/*.test.ts`: a plugin marketplace copy under a local actor dir

## .the gap, precisely

- `jest.unit.config.ts` / `jest.integration.config.ts` `testMatch` ignore `**/.yalc/**` only
- `rhx rmsafe` keeps its trash inside the repo, under `.agent/.cache`; jest walks it
- the actor dir holds third-party test files no repo owns
- ci checks out clean, so ci stays green; any clone with these dirs gets a red `--thorough` run with no cause of its own

## .the shape of the fix

- in the declapract jest config templates, add `'!**/.agent/.cache/**'` and `'!**/.agent/.actors/**'` to `testMatch` (or `testPathIgnorePatterns`)
- one clamp: a temp repo with a red `*.test.ts` under `.agent/.cache/`; the run stays green

## .why it is not done in this round

declastruct-aws carries the two globs in its own three configs (fulcrum F7), so its runs are green now. the template is declapract's: until it carries the globs, every other ehmpathy repo still walks these dirs, and the next upgrade here may revert the local edit.
