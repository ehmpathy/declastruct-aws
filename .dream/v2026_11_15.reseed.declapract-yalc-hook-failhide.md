## .the gap, precisely

```bash
if command -v node > /dev/null 2>&1 && [ -x ./node_modules/.bin/yalc ]; then
    if [ "$(./node_modules/.bin/yalc check 2>/dev/null)" ]; then
        echo "✋ package.json has yalc references. ..."
    fi
else
    echo "🟡 yalc not available, wont check for yalc references"
fi
```

1. `2>/dev/null` inside a `[ "$(…)" ]` test: a yalc that fails outright prints naught to stdout,
   so the hook reads it as "no references" and passes. a failhide
2. the `✋` line has no `ConstraintError:` qualifier, and it does not exit 2, so it never blocks
3. the `else` notice prints to stdout on every commit where yalc is absent, and blames yalc when
   `node` is the absent one

## .the shape of the fix

```bash
if ! command -v node > /dev/null 2>&1 || [ ! -x ./node_modules/.bin/yalc ]; then
  exit 0  # yalc not installed: no yalc references can exist
fi
if ! out=$(./node_modules/.bin/yalc check); then
  printf '✋ ConstraintError: package.json has yalc references\n' >&2
  printf '   └─ fix: npx yalc remove --all\n' >&2
  exit 2
fi
```

confirm `yalc check`'s exit code contract first (does it exit non-zero on found references, or
only print?), and split "references found" from "yalc broke" on that basis.
