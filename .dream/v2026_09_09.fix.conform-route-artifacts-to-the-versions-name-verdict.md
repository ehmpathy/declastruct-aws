## .the shape of the fix

do it **as part of the F10 shape rewrite, not before it** — the two touch the same lines, and a
rename that lands first produces prose that is correctly spelled and still describes an abolished
shape.

1. **rewrite the shape first.** every case file's code block shows
   `DeclaredAwsS3Bucket.as({ versioning: 'Enabled', publicAccessBlock: …, lifecycle: … })`. under F10
   that is three declared resources in a `getResources()` array, in an order that is now a
   **cross-resource** constraint (`DeclaredAwsS3BucketVersions` **last**, per invariant I-1).
2. **then rename the coordinate** `versioning` → `versions` on axis B, in the census, `dimensions.md`
   and each case file. ⚠️ the rename is a coordinate change, so it must be **total** — a census that
   half-renames an axis position no longer computes its own cell addresses
   (`rule.forbid.itemization-without-coordinates`).
3. **then rename the two files**, and repair every citation of them. both are cited by coordinate
   from the census and the yield, so `Grep` for the old stem before you call it done.
4. **leave every ⛔ row above untouched**, and keep the split visible: a reader must be able to see
   which word is ours and which is aws's.

## .why it is not done in this round

it fails **CLEAN**, on three counts:

- it ripples into **20 files** the council's verdicts did not otherwise open
- two of the sites are **filenames**, and a filename change breaks every coordinate that cites it —
  so a partial pass leaves the census unable to compute its own addresses
- the ⛔ classes sit **interleaved** with the 🔴 ones in the same paragraphs, so no mechanical
  find-and-replace is safe, and a hand pass over 258 sites inside a stone that is already at
  `--as blocked` is a large uninspected diff
