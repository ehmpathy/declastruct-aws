badge is an x509 cert. the description carries weight: `readme.reach.md` step 2 tells a revoked
reach from an unwired one by whether the stated intent still matches the trust policy.

instance role or a roles anywhere cert), so no ehmpathy credential is hand-carried onto a foreign
org host'`. the plan then reads one `UPDATE` on `ehmpathy-demo-for-grove` with a `description`
diff and no other field; `setIamRole` sends `UpdateRole` for it. `resources.reach.test.ts` `[case1][t5]` snaps the string, so the fix resnaps it: a reviewed diff of the description alone.
