# case=2 — the applier reads one trust update, then applies on his go

feel: happy · sharp branch on an unexpected plan · care: critipath

## .narrative

the commander opens the crew on his screen. he authenticates to demo, sources `.env`, and plans `account=demo/resources.ts` per `account=demo/readme.md`.

the plan shows one `UPDATE`: `ehmpathy-demo-for-grove`. the diff touches one field, the trust statement's `action`: `sts:AssumeRole` becomes `[sts:AssumeRole, sts:TagSession, sts:SetSourceIdentity]`. the principal, description, tags, attachments, and `ehmpathy-demo-oidc` all read `KEEP`.

he says go. the apply runs from that same plan file.

before the go, anyone with test creds can read the same plan with one call: `rhx aws.auth.demo.plan`. it unlocks keyrack, finds the reach pair (`.env`, else the shell, else the live role, with a warn that the principal goes unchecked), plans into its own `.temp/plan.readonly.json`, and closes with a tally: `UPDATE: 1`, the row named. it never applies, and apply never reads its file. a slip in its inputs (keyrack refused, creds that do not authenticate, half a pair, a principal that is not one role arn) exits loud with the fix named, before any plan.

sharp branch: the plan shows a principal diff, a second `UPDATE`, or any `CREATE`/`DESTROY`. that is a STOP. the most likely cause is a wrong `.env` pair, which `readme.reach.md` already covers. no apply runs on a plan that does not match. a pair set but malformed (a blank name, a padded or quoted paste, a whole arn) never reaches a row: the plan refuses at the read, names the var, and states the shape it wants.

## .bdd sketch

```
given('[case2] the fix merged, demo admin creds, .env sourced')
  when('[t0] the applier plans account=demo')
    then('exactly one row is UPDATE: ehmpathy-demo-for-grove')
    then('its diff changes the trust statement action alone')
    then('the trust principal is unchanged')
    then('every other row is KEEP, ehmpathy-demo-oidc included')
  when('[t1] the plan shows any other change')
    then('the applier stops; no apply runs')
  when('[t2] the commander says go')
    then('apply runs from the plan file just read, and succeeds')
  when('[t3] a reader runs rhx aws.auth.demo.plan, before the go')
    then('the tally reads UPDATE: 1 on ehmpathy-demo-for-grove, all else KEEP')
    then('under that row, the changed lines show the action alone; a principal line there is a STOP')
    then('it names where the reach pair came from')
    then('no apply runs; the plan file is not the one apply reads')
  when('[t4] its inputs slip: keyrack, creds, half a pair, or a bad principal')
    then('it exits 2 (or 1 on a fault) with the fix named, before any plan')
  when('[t5] the .env holds a pair set but malformed: blank, padded, quoted, or an arn')
    then('the plan refuses before any row, and names the var and its shape')
    then('a pathed role name (svc/name) is not a slip; it passes unaltered')
```
