```
   ├─ diffs: since-main → files: 38

   └─ joined via intersect → files: 0
✋ BadRequestError: combined scope resolves to zero files
```

- **r2 ergo-contract-snapshots**, **r3 mech-external-contracts**, **r4 ergo-acceptance-journey-coverage**,
  **r5 ergo-snapshot-visual-blemishes**, **r6 mech-given-when-then**, **r7 mech-test-intent**.
- **diagnosis:** their `paths` glob resolves to **null/none**, so `diffs ∩ paths = 0` and the
  reviewer harness hard-errors instead of a graceful empty-scope skip. this is a reviewer **scope
  config** issue, not a defect in the fix — this behavior legitimately touches no `.snap`, no
  `*.acceptance.test.ts`, and no `src/contract/**` files, so those rubrics have no content to grade.
- the guard marks them `terminal — does not block higher levels` (L3 did run: r9/r10/r11 graded),
  but a `constraint` is not an approval, so **final passage is blocked "by constraints"**.

## why this is genuinely foreman-only

  skip gracefully on empty scope — is a **route/guard-definition** change, owned by the route owner,
  not the driver. i cannot edit the reviewer scope config from here.
