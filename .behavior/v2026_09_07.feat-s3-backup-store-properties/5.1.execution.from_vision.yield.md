## .the shape being built

```ts
access: { public: 'blocked' | { acls: { block, ignore }, policies: { block, restrict } } },
lifecycle: {
  objects:    { expire: IsoDurationInDays | null, transitions: [ … ] },   // ANY bucket
  versions:   false | { status: 'enabled' | 'suspended',
                        expire: VersionExpiry | null },                   // only if versioned
  multiparts: { expire: IsoDurationInDays | null },
} | null,

type VersionExpiry = { after: IsoDurationInDays; keep: number | null }
                   | { after: null;             keep: number };
```

### the serialize-safety gap — found in self-review, fixed

a coverage self-review (role-standards) surfaced a **blocker** no local gate had exercised:
declastruct decides KEEP via `serialize(omitReadonly(remote)) === serialize(omitReadonly(desired))`
(`computeChange.js`), and `domain-objects` **refuses** to serialize a DomainObject that carries an
object-valued property NOT declared in `static nested` (throws `DomainObjectNotSafeToManipulate`).
the new shape had FIVE such un-hydrated leaf bags — `acls`, `policies`, and the three `expire`
bags — so at PLAN time the serialize would throw and the wish's entire deliverable could not be
computed. it read green locally (the cast test compares with `.toEqual`, never `serialize`; the
real plan runs only against aws, 5c-gated).

**fix — drive-local, and it KEEPS F18/I-9 intact.** every leaf bag became a nested DomainObject:

- `IsoDurationInDays` → a `DomainLiteral` class
- `acls`/`policies` → `DeclaredAwsS3BucketPublicAccessAcls` / `…Policies`, added to
  `DeclaredAwsS3BucketPublicAccess.static.nested`
- `expire` on `versions` → hydrates into a widened `DeclaredAwsS3BucketVersionExpiry`
  (`{ after: IsoDurationInDays | null, keep: number | null }`), while the FIELD stays the
  `VersionExpiry` union — exactly as `public: 'blocked' | DeclaredAwsS3BucketPublicAccess` keeps a
  union field over a nested arm. so the all-null arm stays a **compile** error (F18 rung 1); no
  drop to a runtime guard was needed.

**clamp** — `DeclaredAwsS3Bucket.serialize.test.ts` runs declastruct's exact compare path on the
vision's backup store: it was RED (serialize threw) before the fix, GREEN after, and asserts the
serialization is stable across two identical builds (the KEEP property). `types` + `lint` green.

⚠️ my prior read of this had escalated it as a wisher-scope reversal of F18 — that was an
over-escalation. the union is preserved at the field type; the fix needed no wisher call.
