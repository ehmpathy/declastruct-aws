## .the shape of the ask, in one line

four properties are absent from `declastruct-aws@1.11.0` and a backup store cannot be declared
without them: bucket **versioning**, bucket **public-access block**, lifecycle **abort of
incomplete multipart uploads**, lifecycle **expiry of noncurrent versions**.

⚠️ `versioning` is aws's own word — `Put/GetBucketVersioning`. it stays as the api names it.

## ⚠️ .the criterion that actually decides this

the issue says it outright, and it is the one to keep in view from the first line of code:

> the ask is not merely "add the fields" but "add them such that a plan → apply → plan converges
> to KEEP".

each of the four round-trips through an aws api that **canonicalizes**, and each has a distinct
absent/unset read (`NoSuchPublicAccessBlockConfiguration` is a 404; `GetBucketVersioning` returns
an empty body; absent lifecycle sub-rules are omitted rather than nulled). a naive
`serialize(remote) === serialize(desired)` compare yields a **permadrift** — a plan that reads
UPDATE forever and that no apply can ever close.
