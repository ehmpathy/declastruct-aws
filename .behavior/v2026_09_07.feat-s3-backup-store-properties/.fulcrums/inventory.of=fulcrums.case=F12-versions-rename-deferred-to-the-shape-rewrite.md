## .taken — (a), and flagged at 85%

three reasons, and the third is the one that decides it:

1. ⚫ **the two changes touch the same lines.** F10 abolishes the **field**; the verdict renames the
   **resource**. a rename that lands first yields prose that is correctly spelled and still shows
   `DeclaredAwsS3Bucket.as({ versions: 'Enabled', … })` — a shape the council abolished in the
   same breath. ⇒ **the rename would have to be done twice.**
   🔴 **this reason is FALSE twice over.** the second council restored the nested field, so
   `DeclaredAwsS3Bucket.as({ versions: 'Enabled', … })` is the shipped shape — and the rename that
   landed anyway needed no second pass. ⇒ **a deferral argued from another fulcrum's verdict inherits
   that verdict's volatility**, and this one was written the same day the verdict it rested on was
   issued.
2. **two of the sites are filenames**, each cited by coordinate from the census and the yield. a
   partial pass leaves the census unable to compute its own cell addresses
   (`rule.forbid.itemization-without-coordinates`).
3. 🔴 **the ⛔ and 🔴 classes are interleaved in the same paragraphs.** `PutBucketVersioning`,
   `s3:GetBucketVersioning` and the wish's own line must **not** change; the axis label must. no
   mechanical find-and-replace can tell them apart, so option (b) is a 258-site hand pass — a large
   uninspected diff written **after** the last review read, which is the exact defect this drive
   already disclosed once.

### 🔴 what the execution falsified — reason 3 was wrong, and it was the deciding reason

> *"no mechanical find-and-replace can tell them apart, so option (b) is a 258-site hand pass."*

**both halves are false, and the second follows from the first.**

| the claim | what the execution measured |
|---|---|
| the classes cannot be told apart mechanically | ⛔ they can, on **two** axes. **case** parts aws's `Get/PutBucketVersioning` from every lowercase site at zero cost, and **form** parts ours from aws's prose — `` `versions` ``, `versions:`, `"versions"`, `versions=`, `\| versions \|`, `B = versions` are all ours, and none appears in aws's prose |
| 258 sites, all owed | ⛔ **~90 were ours.** the other ~164 are aws's symbols, aws's IAM actions, and aws's verbatim prose about aws's feature — each **exempt by the verdict's own words** (*"because we do not own those"*) |
| a large uninspected diff | ⛔ **eight `sedreplace` passes, each previewed in plan mode before apply.** one site was caught wrongly (`case=7`, an aws quote whose label ends in a colon) and restored by hand |

⇒ 🔴 **the lesson generalizes past this fulcrum: a rename is scoped by OWNERSHIP, and a `grep -c`
of the word cannot see ownership.** the count that made the pass look expensive was a count of a
set the verdict had already excluded — so **the deferral was argued from the wrong denominator.**

⚠️ **reasons 1 and 2 were sound and remain so** — the two changes do touch the same lines, and a
partial coordinate rename would break the census. what they justify is **care**, never a deferral:
reason 2 is an argument for a *total* pass, and it was executed as one.
