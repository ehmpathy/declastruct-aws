## design (from vision, wisher-approved)

param name segment = `${sanislug(comment)}-${hash(comment)}`
- `sanislug` = replace illegal chars with `-`, collapse + trim, length-bound → readable, lossy
- `hash` = `asHashShake256(comment, { bytes: 8 })` from `hash-fns` → 16 hex chars, collision-safe
- exid is NOT hashed (wisher confirmed) — every extant exid is already SSM-safe
- the readable comment still lives in the param VALUE (unchanged)
